# Chapter 3 Recipes

These recipes select the approved Chapter 3 experimental units from the
complete benchmark. They do not redefine protocol rules, robot environments,
pass standards, or required recording.

- `b1.json` contains the 350-replicate, ten-robot primary condition plus the
  175-replicate scaffolding ablation. It remains blocked until one fixed,
  reference-calibrated validation bundle per robot is materialized.
- `b2.json` contains 280 episodes for Code-BT if its audit, task set, fixed
  reference drivers, interfaces, and seven backbone transports are admitted.
