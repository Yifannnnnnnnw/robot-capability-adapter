# Fixed Demo scenes

These nine scene sets preserve the existing robot XML and initial keyframes
used by the fixed Demo tasks. Shared meshes remain in the base model folders.

The task-to-scene mapping and initial states are in
[`auto_adapter/demo_tasks.yaml`](../../../auto_adapter/demo_tasks.yaml). Other
robots use their existing base scenes or explicit push scenes, so this directory
is not the full robot inventory.

These are fixed downstream task inputs. A synthesis run creates its own
validation scenes and physical criteria from the current capability design.
See [the asset guide](../../../docs/ASSETS.md) for resource paths and licenses.
