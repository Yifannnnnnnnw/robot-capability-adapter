# Fixed DEMO scenes

These nine scene sets preserve the existing robot XML and initial keyframes
used by the fixed DEMO tasks. They were relocated unchanged from the retired
`assets/mjcf/capabilities/` tree; shared meshes remain in the base model folders.

The authoritative task-to-scene mapping and initial states are in
`AA1/auto_adapter/demo_tasks.yaml`. Other robots use their existing base scenes
or explicit push scenes, so this directory is not the full robot inventory.
See `AA1/docs/DEMO_CONFIGURATION.md` for the distinction between fixed DEMO
inputs and a run's generated validation cases and criteria.
