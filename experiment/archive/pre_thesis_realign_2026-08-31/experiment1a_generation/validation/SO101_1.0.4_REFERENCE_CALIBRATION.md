# SO-101 1.0.4 fixed-suite reference calibration

This note records the two task-blind instance corrections that distinguish
`experiment1-b1-fixed-suite::robotstudio_so101::v6` from v5. It is diagnostic
provenance, not a new capability contract or a change to any public threshold.

## A3-H3 reset correction

- Request remains `opening_fraction=0.5`, `max_duration_s=3.0`.
- The gripper joint and actuator reset changed from `1.0 rad` to the declared
  closed endpoint `-0.17453 rad`.
- The closed endpoint is already the package-bound value in the A3 binding;
  it was not inferred from a candidate Driver.

  declared full-travel excursion. Starting H3 at `1.0 rad`, already close to
  the half-open target, made that physical-excursion check depend on the reset
  accident rather than on whether the Driver implemented the requested
  capability. The closed reset restores a measurable, in-range excursion.
