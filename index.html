THE METHOD

Build the interface.
Verify the behaviour.

A planner can compose tools, but a new robot still needs its own implementation. AutoAdapter brings that robot-specific software into the generation loop.

  1. 01 / DESIGN

    Define capabilities

    Turn robot descriptions and target tasks into reusable operations and measurable behavioural requirements.

    Robot information → interface & tests
  2. 02 / GENERATE · ReAct

    Synthesise a driver

    Implement those operations in Python, using the robot's actual joints, actuators and observations.

    Capability interface → driver
  3. 03 / VALIDATE

    Observe and repair

    An independent Harness reads MuJoCo state, applies fixed criteria and provides feedback for driver repair.

    Physical state → verdict & feedback
  4. 04 / USE · ReCAP

    Compose operations

    ReCAP calls the generated capabilities to perform downstream tasks, whose outcomes are evaluated separately.

    Reusable operations → tasks
Why independent checks?

Executable code can still produce the wrong movement. The Harness judges simulator observations outside the candidate driver's control. Capability specifications and tests are still authored during Design.
