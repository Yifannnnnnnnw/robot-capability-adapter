\title{Auto-Adapter: Robot-Specific Driver Synthesis with Independent Closed-Loop Validation}
\author{Yifan Wang}
\department{Department of Computer Science}

\maketitle
\makedeclaration

\begin{abstract}
This thesis investigates how action and observation requests from LLM-based embodied agents can be translated into executable robot operations. Deploying such an agent on a new robot requires a Python driver that provides access to robots. This driver typically requires manual implementation, adding development effort for each robot platform. Existing approaches, including ReAct, Code as Policies, and CodeAct, rely on available tools and APIs, leaving the implementation of the robot-specific interface outside their scope. This motivates the question of whether an LLM can also generate the driver that connects an embodied agent to a new robot.
To investigate this question, this thesis presents Auto-Adapter, an LLM-agent pipeline for robot driver generation. Given a robot description and target tasks, it proposes reusable robot operations, implements them in a self-contained Python driver, and iteratively refines the implementation using simulation feedback from an independent test harness. Auto-Adapter generated executable drivers in 72.7\% of synthesis runs.
Synthesis averaged 17.3 min and an estimated US\$8.48 per attempt.
The project repository
is available at \url{https://github.com/Yifannnnnnnnw/robot-capability-adapter}.

The evaluation comprises three experiments.\\
\textbf{Experiment 1---Auto-Adapter Framework.}
The first experiment evaluates the Auto-Adapter framework, from designing
reusable robot capabilities to generating drivers that implement these
capabilities. Independent validation assesses the behaviour produced by each
driver using observations recorded by the MuJoCo simulator. The experiment
also assesses whether the generated drivers can be used by high-level
planners to complete embodied tasks.

\textbf{Experiment 2---AutoAdapter-Bench.} AutoAdapter-Bench compares LLM
performance in two roles: generating robot-specific drivers and making
high-level task decisions through existing drivers. The evaluation
distinguishes the behavioural conformance of generated drivers from success
in completing embodied tasks. The benchmark also reports estimated model
usage costs and elapsed time, allowing model performance and resource
requirements to be compared separately within each role.

\textbf{Experiment 3---Cross-Robot Evaluation.} The final experiment applies
Auto-Adapter across different robot configurations. Its purpose is to assess
whether the framework performs consistently well across robots with different
structures and control requirements. The evaluation compares driver
validation outcomes and embodied task completion across the selected robots.
It also examines difficulties encountered during driver generation and task
execution to identify limitations associated with each robot configuration.


Within the evaluated scope, the thesis makes three scientific contributions:
\vspace{-\parskip}
\begin{enumerate}[leftmargin=*,labelsep=.8em,nosep]

  \item \textbf{A framework for robot-specific driver generation.}
  Auto-Adapter introduces a method for large language models (LLMs) to derive
  reusable capabilities from robot descriptions and task requirements and
  implement them as robot-specific drivers. The resulting interfaces separate
  robot-specific implementation from task-level planning, allowing the
  generated software to be reused across embodied tasks.

  \item \textbf{Independent capability validation through physics simulation.}
  The framework executes generated drivers in MuJoCo and assesses their
  capabilities against predefined behavioural requirements using independently
  recorded robot state. Validation relies on observed motion and interaction
  outcomes rather than model self-reports.

  \item \textbf{Separating driver generation from high-level decision-making.}
  AutoAdapter-Bench evaluates LLMs as driver generators and high-level
  decision-makers. It separately assesses the behavioural conformance of
  generated drivers and task completion through existing drivers, enabling
  comparison of model performance across these roles.

\end{enumerate}

The thesis also makes three bounded,
industry-relevant contributions:
\vspace{-\parskip}
\begin{enumerate}[leftmargin=*,labelsep=.8em,nosep]

  \item \textbf{Reusable software interfaces for robot integration.}
  Generated drivers expose robot-specific operations through callable
  interfaces that high-level agents can reuse across tasks. These interfaces
  provide software components for integrating simulated robots into
  agent-based systems.

  \item \textbf{Behavioural evidence for driver inspection and repair.}
  Independent validation provides measurements and failure diagnostics that
  help developers identify unmet requirements and guide driver repair before
  downstream task execution.

  \item \textbf{Evidence for model selection.}
  The benchmark reports behavioural performance alongside estimated model
  usage costs and elapsed time for each role. These measurements inform model
  selection and resource allocation within the evaluated conditions.

\end{enumerate}


\end{abstract}
