\noindent\footnotesize\textit{Acceptance rule.} Each capability is evaluated
on three hidden combinations of target, initial state, and parameters. A
capability passes only if all three cases pass, and a generated driver passes
B1 only if every capability assigned to its robot passes. Each trial must also
satisfy the common closed-loop, canonical-physics, control-range, unintended-
motion, contact-integrity, maximum-penetration, and complete-video checks.
