\chapter{Appendix}
\label{chap:appendix}

\begin{quote}\itshape
The objective of this appendix is to provide the detailed reference material
that supports the benchmark and experimental chapters. It begins by listing
the declared LLM, robot, and control-architecture scope. It then records the
generated-driver capabilities and validation criteria, followed by the
canonical task libraries and their passing standards. Finally, it identifies
the external sources from which these standards were defined or adapted and
states the associated scope, acceptance, decision, and provenance boundaries.
\end{quote}

\noindent\footnotesize\textit{Acceptance rule.} Each capability is evaluated
on three hidden combinations of target, initial state, and parameters. A
capability passes only if all three cases pass, and a generated driver passes
B1 only if every capability assigned to its robot passes. Each trial must also
satisfy the common closed-loop, canonical-physics, control-range, unintended-
motion, contact-integrity, maximum-penetration, and complete-video checks.
